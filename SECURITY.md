# Security

## Reporting

Please do not publish sensitive vulnerabilities in public issues. Use the
repository's private security-reporting mechanism once one is configured, or
contact the maintainer directly: **Jubilee** ([@Jubilee-001](https://github.com/Jubilee-001)).

## Scope

Review authentication, authorization, transaction construction, input validation,
secret handling, replay protection, and any boundary between off-chain state and
Stellar state.

## Current status

This repository is a development baseline and has not been represented as an audited
security system. Production deployment requires a security review and environment
hardening.
